This project automatically processes three short Modern Standard Arabic documents and builds a positional inverted index keyed by lemmas. The Jupyter notebook is the main working file, and no posting list is entered manually.

## Project structure

```text
Assignment3_Inverted_Index.ipynb    Main executed notebook
data/documents.json                 Original documents
src/preprocess.py                   Normalization, tokenization, stop words, lemmatization
src/build_index.py                  Index construction, export, and validation

output/                             Generated diagnostics and index files
report/Assignment3_Inverted_Index.tex XeLaTeX report
report/generated_content.tex        Report data generated by Python

```

## Environment and lemmatizer

- Python 3.11
- CAMeL Tools 1.6.0
- CALIMA MSA morphology database: `morphology-db-msa-r13`
- MSA MLE disambiguator: `disambig-mle-calima-msa-r13`

The program uses `MLEDisambiguator.pretrained("calima-msa-r13")`. For each token it takes the highest-ranked analysis selected by the pretrained MLE model and uses its `lex` field as the dictionary lemma. The lemma is dediacritized and conservatively normalized for indexing. Unknown unanalyzed tokens retain their normalized surface form and are marked in `token_diagnostics.csv`; the included documents currently produce analyses for every token.

Lemmatization is used instead of stemming because a lemma is a meaningful dictionary/base form, while stemming may aggressively reduce a word to a stem or root. The instructor explicitly requested lemmatization. The model is an established morphological system, but its analysis can still be imperfect for ambiguous words.

**Lemmatization was used instead of stemming because the instructor explicitly requested lemmatization.**

## Installation

Create and activate a virtual environment, then install the Python package:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Install the two required linguistic resources inside the project:

```bash
mkdir -p .camel_tools_data
export CAMELTOOLS_DATA="$PWD/.camel_tools_data"
camel_data -i morphology-db-msa-r13
camel_data -i disambig-mle-calima-msa-r13
```

The morphology database and MLE model are separate downloads and cannot be declared in `requirements.txt`. They require approximately 129 MB before extraction.

## Run

Open `Assignment3_Inverted_Index.ipynb` in Jupyter or VS Code and run all cells from top to bottom. The notebook displays every intermediate stage and saves the requested CSV files.

The equivalent command-line pipeline is:

```bash
python src/main.py
```

The script prints the original documents, tokenization, normalized tokens, removed stop words, lemmas with original positions, the final index, and validation results. It generates:

- `output/token_diagnostics.csv`
- `output/processing_details.csv`
- `output/processed_documents.txt`
- `output/positional_inverted_index.csv`
- `output/positional_inverted_index.txt`
- `report/generated_content.tex`

Compile the PDF with:

```bash
cd report
xelatex -interaction=nonstopmode -halt-on-error Assignment3_Inverted_Index.tex
xelatex -interaction=nonstopmode -halt-on-error Assignment3_Inverted_Index.tex
```

Positions are assigned before stop-word removal. Therefore, deleting a stop word never changes the positions of later tokens.

## Interactive demo

The notebook ends with an optional section named **Try Your Own Arabic Text**. Enter one Arabic sentence when prompted. The section reuses the same `ArabicPreprocessor` and `build_positional_index` functions as the assignment pipeline; it does not contain a second preprocessing implementation.

It displays:

- each original and normalized token at its original position;
- the CAMeL Tools lemma, or `—` for a removed stop word;
- whether each token is a stop word; and
- a small `USER_DOC` positional index containing only non-stop-word lemmas.

Empty input is handled with a short message. Nothing entered in this optional section changes the three original documents, the submitted index, the CSV results, or the PDF report.
