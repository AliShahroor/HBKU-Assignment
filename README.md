# HBKU-Assignment

- [Gemini API Translation Lab](Gemini-Translation-Lab/): Automate Arabic-to-English translation with Python, Google Colab, and the Gemini API.
- [BERT for Palestinian POS Tagging](BERT-Palestinian-POS-Tagging/): Fine-tune AraBERT on Curras plus a Palestinian digital-campus corpus and compare it with a controlled Curras-only baseline
- [Arabic Word2Vec](Arabic-Word2Vec/): Construct a 3,007-token Arabic computer-science corpus, train skip-gram Word2Vec, and report five cosine similarities.
- [ChatGPT API Translation](ChatGPT-API-Translation/): Translate 200 Palestinian Arabic sentences with zero-shot and few-shot prompting, then compare quality, cost, and a free-model subset.
- [Applied Deep Learning](AppliedDeeplearning/): LoRA fine-tuning of Qwen3-1.7B for a course greeting convention, with evaluation, ablations and GGUF/Ollama deployment.
